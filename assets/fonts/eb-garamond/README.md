# EB Garamond

`eb-garamond-latin-400-v33.woff2` is the Latin webfont for EB Garamond Regular
(400, normal), distributed by Google Fonts. Only this face is used by the
case-study pages. It is served as a static asset so the private GT America
Pages Function and its R2 allowlist remain unchanged.

Source stylesheet: https://fonts.googleapis.com/css2?family=EB+Garamond:wght@400&display=swap

Downloaded 2026-09-16 from:
https://fonts.gstatic.com/s/ebgaramond/v33/SlGDmQSNjdsmc35JDF1K5E55YMjF_7DPuGi-6_RkBI9_WamXgHlI.woff2

their corresponding subsets; no other weights or italic face are included.
